
# Individual Reflection – LI (Chu), Product Owner / Developer
My main responsibilities in the CampusFix project were serving as the Product Owner and developing Part C.

As Product Owner, I wrote the story backlog document and managed and prioritized Jira items, including CF-11, CF-12 and CF-20.

For Part C (CF-20, PR #2), I fixed a defect where searching for `%` or `_` returned all reports because these characters were treated as SQL wildcards. 

I worked with the related test cases to verify that special characters are now handled correctly. 

During the code review, an indentation error was identified in `database.py`, which showed me the importance of careful review and testing.

I also tested TC-06 to TC-08, which cover case-insensitive keyword search, location filtering and searches with no matching results. 

I learned how to run tests in the terminal and how to connect test evidence with Jira issues.

One difficulty I faced was that I was initially unfamiliar with GitHub and terminal commands. 

Sometimes I did not know how to open the terminal, run tests or understand the results. 

By practising step by step, I gradually improved.

This project taught me that software development involves more than writing code: communication, teamwork, testing and task management are equally important. 

In future projects, I will run tests before submitting pull requests, check code changes more carefully, and link Jira issues, pull requests and test results so that the process is organised and traceable.

I used AI assistance to understand GitHub operations, troubleshoot issues and improve the wording of this reflection. 

I reviewed the content and took part in the development and review process myself.

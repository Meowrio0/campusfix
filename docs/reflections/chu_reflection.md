### CampusFix Project Reflection (Product Owner / Developer)

In the CampusFix project, I served as both the Product Owner (PO) and a Developer. My main responsibilities included managing and prioritizing Jira tasks, improving keyword search and location filtering, and fixing SQL wildcard issues.

During the project, I learned how to use GitHub to modify code, create Pull Requests, and review other team members' work. At first, I was not familiar with GitHub and the testing process, so I faced several difficulties. However, through hands-on practice, I gradually became more confident in using these tools and understanding version control.

I was also responsible for test cases TC-06 to TC-08. Through these tasks, I learned how to run automated tests using the terminal, check test results, and document testing evidence in Jira.

Overall, this project helped me understand that software development is not just about writing code. It also requires effective communication, teamwork, testing, and task management. This experience improved my problem-solving skills and gave me a better understanding of Agile software development.
